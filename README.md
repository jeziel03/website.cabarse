# Dakingo – Online Bakery (website recreation)

Recreation of the Dakingo bakery landing page design (reference: `assets/reference.jpg`).

## Files
- `index.html` – markup (header, nav, hero, menu, bestsellers, promise, gallery, banner, footer)
- `style.css` – styles, responsive breakpoint at 620px, light/dark theme
- `script.js` – search, category filters, cart, wishlist, subscribe validation, toasts

## Sections
1. Header and navigation  2. Hero offer  3. Menu categories  4. Bestsellers  5. Our Promise and gallery  6. Banner and footer

## Assets
Cake and gallery pictures are inline SVG illustrations that stand in for the photos. Font: Baloo 2 (Google Fonts).

## Run
Open `index.html` in a browser. No build step.

## Deploy (GitHub Pages)
Push these files to a repo, then Settings > Pages > Deploy from branch `main` / root.
